# notebooklm-model-processos-gerenciais

Projeto utilizando Notebook LLM para criação de guia de estudos na área de processos Gerenciais

# Contexto e Objetivos
Utilizando o Gemini Notebooks( antigo notebook LLM) criei um guia de estudos para a área de processos gerenciais, apresentando conceitos da área e o papel do gestor de processos no ambiente corporativo.
Os materiais utilizados para o teste foram resultados da disciplina de Tópicos em processos Gerenciais ministrado no curso de Processos Gerenciais da UniFECAF, além da pesquisa em sites que falam sobre Qualidade, gestão de conflitos e outros temas relacionados.

O guia possui como objetivo, orientar alunos de processos gerenciais sobre sua atuação no mercado de trabalho
Ilustrar de forma simples papeis que podem ser exercidos por esse profissional;
